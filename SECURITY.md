# Security

Please report a vulnerability privately: [Security → Report a vulnerability](https://github.com/MRiediger/sc-cargoplan-shipdata/security/advisories/new), not as a public issue.

This repository contains the data pipeline only. Issues in the SC-CargoPlan app belong to [sc-cargoplan](https://github.com/MRiediger/sc-cargoplan/security/advisories/new).

Only the latest data release gets fixes.
