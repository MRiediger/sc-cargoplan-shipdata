# sc-cargoplan-shipdata

Ship data for [SC-CargoPlan](https://github.com/MRiediger/sc-cargoplan): cargo racks, outlines and holograms, built by
a pipeline from the Motherlode catalog and published as data releases the app downloads on its own channel.

Status: Phase 12, spike S12.0. Nothing here is the pipeline yet. `spike/` and `.github/workflows/spike.yml` are
throwaway code that measures; see `docs/plans/S12.0-spike.md` and `TASKS.md`.
